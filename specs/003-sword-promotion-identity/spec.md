## User Scenarios & Testing *(mandatory)*

### User Story 1 - 从动作辨认剑系打法 (Priority: P1)

作为玩家，我希望从人物轮廓和实际攻击看出基础剑士、剑圣与深渊剑士的差别，选择贴近敌群的双斩／旋斩，或长弧攻击与续航，而不必只看职业名称和颜色。

**Why this priority**: 转职是现有角色成长的重要卖点；让已有机制可见，才能让永久选择显得有价值，并形成清楚的实机展示。

**Independent Test**: 不改转职页面或治疗提示，分别使用基础剑士及两分支进行相同遭遇；对比待机、移动、普通攻击、第五次攻击的真实画面及灰度画面。

**Acceptance Scenarios**:

1. **Given** 相同剑系英雄分别使用基础职业与两分支，**When** 查看待机、移动及攻击，**Then** 基础单剑、剑圣双刃、深渊长刃具有不同轮廓；去除颜色和职业名称后仍保留这些差别。
2. **Given** 剑圣发动一次普通攻击，**When** 两次弧形伤害同时发生，**Then** 玩家看到方向可辨的双斩轨迹；攻击判定时间、伤害、范围和一次发动的计数不变，不制造第二次延迟伤害的暗示。
3. **Given** 剑圣已实际发动四次攻击，**When** 第五次发动，**Then** 双斩之外显示与周围伤害对应的完整旋斩轮廓；第六次回到普通双斩。
4. **Given** 深渊剑士自动攻击，**When** 攻击发动，**Then** 长刃与延伸剑弧清晰可见，表现方向与已有有效范围一致；不把装饰拖尾表示为额外伤害范围。
5. **Given** 同一职业由另一剑系英雄或同伴使用，**When** 战斗、受伤或倒下，**Then** 保留同一职业动作特征及主角／同伴身份标记，状态优先级仍为死亡、受伤、攻击、移动、待机。

### User Story 2 - 看懂实际续航收益 (Priority: P2)

作为深渊剑士玩家，我希望知道哪次攻击真正恢复了生命，以及实际恢复多少，判断转职的续航价值。

**Why this priority**: 现有治疗已生效，但仅生命条变化不易归因；准确反馈能增强成长满足感，并避免虚假的成功提示。

**Independent Test**: 保留现有角色外观和转职页，分别观察受伤、接近满血、满血、伤害拒绝、多目标及同伴情况下的第五次攻击。

**Acceptance Scenarios**:

1. **Given** 存活的深渊剑士生命不足且已发动四次攻击，**When** 第五次攻击对敌人造成有效伤害并恢复生命，**Then** 恢复者身上出现一次短促回流与实际恢复量，包含本次致死命中带来的有效恢复。
2. **Given** 剩余可恢复生命小于最大生命的2%，**When** 合法治疗生效，**Then** 提示显示受生命上限限制后的实际恢复量，不显示理论治疗量。
3. **Given** 满血、攻击未发动、没有实际伤害、伤害被拒绝或恢复者已死亡，**When** 对应攻击或判定结束，**Then** 不显示回血成功或正数治疗提示；不改变已有计数／治疗规则，不复活。
4. **Given** 第五次攻击命中多个敌人或同时叠加额外斩击，**When** 该次发动结束，**Then** 原有最多一次治疗及一次成功提示成立；第四／第六次不会凭空获得分支治疗。
5. **Given** 恢复者是同伴，**When** 合法治疗发生，**Then** 提示跟随该同伴，不暗示主角获治疗；原有同伴治疗量与伤害规则继续适用。

### User Story 3 - 永久选择前看懂两条分支 (Priority: P3)

作为准备转职的玩家，我希望在现有转职页面直接比较普通攻击与第五次收益，再确认永久选择。

**Why this priority**: 演示把战斗差异带到决策点，降低永久选择时的猜测；无需新增转职层级或重置系统。

**Independent Test**: 只在转职页面展示两条分支演示，检查第五次效果、说明、取消、确认及重新进入；无需进行完整远征。

**Acceptance Scenarios**:

1. **Given** 玩家打开任一剑系英雄的转职页，**When** 查看两分支，**Then** 两者均自动循环演示普通攻击与第五次效果，一个完整循环不超过8秒；清楚标注为演示，配一句玩法说明，并使用与实战一致的轮廓和效果含义。
2. **Given** 演示中的深渊剑士处于可恢复生命的示例状态，**When** 第五次攻击命中示例目标，**Then** 展示长弧、一次治疗及示例实际恢复量；不把示例生命或伤害当成玩家当前状态。
3. **Given** 玩家只观看、切换或取消预览，**When** 返回角色界面或开始远征，**Then** 未消耗道具、未获得奖励、未改变存档／队伍／真实生命／远征攻击计数或随机结果。
4. **Given** 未转职英雄永久等级为14或没有道具，**When** 查看演示，**Then** 仍可比较但不能确认；等级至少15且至少有1个道具时，确认保留一次消耗1道具、永久分支、原被动与等级，以及存档失败后阻止继续并重试的流程。
5. **Given** 玩家离开页面、应用失焦或连续重新打开页面，**When** 演示停止或恢复，**Then** 不留下残影、声音或重复演示；已有确认／取消操作继续可用。

### Edge Cases

- 两条斩击重叠、额外斩击或高攻速：必须保留双斩结构与真实伤害时点；不得为动画清楚而延迟或增加伤害。
- 同次攻击多目标、致死命中、理论治疗超过缺失生命：沿用一次发动最多一次治疗，提示只反映实际增量。
- 满血第五次攻击后才受伤：不补发先前治疗或提示，不改变下一次第五攻击的节奏。
- 受伤或死亡覆盖攻击动作：伤害结算不变；角色姿态遵循既有优先级，效果不能掩盖死亡或伪造继续攻击。
- 旋斩与敌方圆形预警同屏：友方旋斩不可冒用敌方橙色预警／红色危险的视觉语义；主角标记和最近敌方预警保持可辨。
- 暂停、升级、结果、重开：战斗效果按主动时间冻结／清理，恢复不积压补播，旧远征提示不得进入新远征。
- 预览中切换英雄、反复确认、取消或保存失败：演示不能发起真实结算或绕过已有转职与保存保护。
- 盲测人数不足、无完整环境观测或缺少自然操作：对应人工／性能验收保持未验证，不用受控截图或自动通过替代。
- 实施前自然九局缺失或时限未达：不得用自动轨迹、挑选成功局或五人测试替代；保留失败，按002原范围修复并完整重录九局；经2026-10-21用户授权，该项延期验收，不阻止本切片实现。五人理解／盲听、自然九对复放、物理DEV及完整性能环境仍独立记账，不额外升级为开工门槛。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 本功能 MUST 仅增强基础剑士及剑圣／深渊剑士的职业表现，适用于全部可用剑系英雄及其同伴；不得改变其他职业行为。验收：故事1场景1／5、SC-001／005。
- **FR-002**: 待机、移动、攻击 MUST 具有基础单剑、双刃、长刃三种可区分轮廓，遵守原32像素常规角色尺度与清晰像素采样；不以颜色作为唯一差别。死亡／受伤优先级及主角／同伴标记 MUST 保留。验收：故事1场景1／5、SC-001／003。
- **FR-003**: 剑圣 MUST 在原伤害时点表现双斩，每第五次实际发动额外表现完整旋斩；深渊剑士 MUST 表现已有长弧方向与范围。装饰不得暗示额外判定或延迟第二次伤害。验收：故事1场景2–4、SC-001／005。
- **FR-004**: 深渊分支回血成功提示 MUST 仅在该次合法分支治疗实际增加存活恢复者生命时出现，并显示恢复者及实际增量；每次发动至多一次。数值显示到小数点后一位，按实际增量四舍五入；满血／拒绝／无伤害／死亡不显示成功。验收：故事2场景1–5、SC-002。
- **FR-005**: 现有剑系转职页 MUST 为两条分支提供自动循环的普通攻击／第五次效果演示、示例标识和一句玩法说明；演示静音，每循环≤8秒，不新增操作键。验收：故事3场景1／2、SC-004。
- **FR-006**: 预览 MUST 只改变演示状态，不能写入玩家存档、消耗道具、产生奖励或改变真实战斗／随机结果；离页清理，失焦冻结，回焦不追赶补播。验收：故事3场景3／5、SC-004／005。
- **FR-007**: 转职 MUST 保留永久等级≥15、消耗1道具、每名英雄只能选一次分支、无重置、保留等级与被动、取消无消耗及保存失败后的原有阻止／重试语义。验收：故事3场景4、SC-005。
- **FR-008**: 伤害、射程、攻速、治疗量、每第五次发动规则、同伴规则、XP、升级抽取、波次与腐化 MUST 保持原玩法；表现不能改变随机选择或存档兼容性。双弧／多目标仍只算一次发动；无目标未发动不计数，计数每次远征重置。验收：故事1／2、SC-002／005。
- **FR-009**: 新战斗表现 MUST 遵守既有暂停、选择、受伤、死亡、结果和重开规则；不得跨远征残留或恢复补播。预览与真实战斗状态必须互不影响。验收：故事1场景5、故事3场景3／5、边界场景、SC-005。
- **FR-010**: 友方剑系效果 MUST 不遮盖主角标记、生命／升级／暂停信息和最近敌方预警；灰度下保留分支差异，沿用原像素尺度与敌我危险语义。验收：故事1及边界场景、SC-003。
- **FR-011**: 开发版 MUST 保留全界面可见DEV、F9、暂停输入、单一常驻面板、全部原有动作与隔离档；发布版 MUST 继续拒绝初始化与全部调试动作。原有音频及其他职业操作不受影响。验收：SC-005。
- **FR-012**: 交付验收 MUST 保留当前未改动基线版本三职业×种子101／202／303的自然九局待验项；2026-10-21用户授权延期验收，代码／美术／工具可先实施，但不得记为通过。逐局核验首个有效命中≤5主动秒、首次击杀≤10主动秒、首次升级≤30主动秒；具体起始条件与失败处理见Assumptions。其余002人工／复放／环境项目独立开放，不作为额外开工门槛。验证与交付 MUST 区分自动／真实图形／自然操作／人工理解／性能结论，保留失败和旧证据；同步离线开发图鉴、中文实现概览、README链接及受影响的开发／任务记录。002未完成验收不得因本功能交付自动关闭。验收：冻结基线版本的九局记录、SC-006及交付记录。

### Key Entities *(include if feature involves data)*

- **剑系职业身份**：基础剑士或两条分支，包含轮廓、动作及已有普通／第五次攻击含义；属于职业，独立于英雄姓名与被动。
- **实际攻击／治疗结果**：真实发动次数、方向、作用范围、恢复者和实际恢复量；提示只能反映已发生的结果。
- **转职演示**：标明示例的分支动作与第五次收益循环；独立于真实档案、战斗状态与奖励。
- **验收会话**：版本、起始档、英雄／职业／同伴、种子、操作／选择、真实观察与结果；人工回答不可由自动结果代填。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001 · 职业理解**：5名未接触改版的真实玩家，先查看两分支预览，再随机观看不带职业名的普通／第五次攻击片段，各操作两分支3个主动分钟；至少4人分别正确说出剑圣双斩＋第五次旋斩、深渊长弧＋第五次有效伤害回血，并给出偏好及与玩法相关的理由。使用同一剑系英雄、永久15级、无同伴、相同种子／起始条件的独立档；试玩无DEV干预。保留原话、死亡、疲劳和重试意愿；偏好不等同留存或销量。
- **SC-002 · 反馈可信**：第4／5／6次、空挥、拒绝、满血、接近满血、多目标、额外斩击、致死命中、死亡与同伴的验证案例中，错误／重复的回血成功提示为0；正数恢复提示与对应实际恢复量的差值≤0.05生命。伤害与治疗数值、目标和发动次数相对改前均不变。
- **SC-003 · 画面辨识**：在1280×720、1920×1080、1371×813真实战斗画面中，两分支动作在灰度下仍可区分。使用同英雄15级、无同伴、同种子起始条件，制作三尺寸×两分支×普通／第五次攻击的12段灰度实机片段，每段播放1秒一次；去除职业名、数值等文字答案线索，保留实际轮廓、动作及剑弧，随机排序。SC-001同组至少4人各正确识别≥10/12段的分支，且普通／第五次两组分别≥5/6；首答计分，“不确定”计错，不提示答案。另建立包含双同伴、腐化100、首领预警的10张密集截图并随机排序；同组至少4人各在至少8张图的一秒展示中，同时指出主角和距离主角最近的敌方预警（同距离均认可）。两项分别达标才通过SC-003；无HUD／关键操作遮挡，保留全部原图、片段、回答与失败样本。
- **SC-004 · 决策预览**：两分支均在8秒内完成一次普通攻击到第五次收益的演示；连续观察至少10个完整循环并进行10次开关页，真实档案、道具、奖励、生命、远征计数和后续随机结果变化为0。等级14／15、道具0／1、取消／确认／保存失败路径全部符合既有条件。
- **SC-005 · 玩法与开发保护**：固定种子101／202／303、相同起始档／输入／选择下，改前后玩法状态、伤害／治疗结果、升级与事件结果一致；受影响剑系与既有其他职业、保存、暂停、重开和DEV／发布限制检查无新增失败。表现开关、预览访问与否均不改变玩法结果。
- **SC-006 · 流畅度**：同机发布版改前／改后各预热30主动秒、采样120主动秒，保持100常规敌人＋1首领、双同伴、至少30效果、至少100活动弹体、500宝石及腐化100；改后帧时p95≤16.67ms、p99≤25ms。120秒样本划分为12个连续、互不重叠的10主动秒窗口，每个窗口两版本均须有剑圣实际双斩发动≥5次、第五次旋斩≥1次、深渊长弧发动≥5次和第五次合法实际治疗≥1次；候选版每窗四类对应表现各至少有1个实际渲染帧。冻结相同的测试队伍、目标布局及周期缺血时序，使用真实攻击／治疗路径；任一窗口缺项则采样无效，预热、占位效果或人工发布提示不能充数。使用Q1已有参考负载及环境基线，记录实际设备／显示／音频与后台观测限制；不能减少负载达标。该样本不关闭历史参考机或其他种子验收。
