## 统一语言

冷石、断拱、潮痕与紫色侵蚀构成暗黑幻想海岸神殿；安静的地面承托可爱、轮廓清晰的小队。恐怖来自不对称、空洞、单眼与异生肢体，不依赖写实血腥或满屏噪点。纯2D近俯视，正交地面网格；不画等距菱形地砖，不用3D或倾斜镜头。Concept 2/3原图缺失，以下只依据文字方向，不能声称还原参考图。

Fantasy使用暖皮肤、金属、浅青友方边缘；eldritch使用冷紫、断裂轮廓和异生眼。友方紫法术必须有浅青十字星/封闭光核；敌方腐化采用分叉/缺口，不靠紫色辨敌我。主角实线环、同伴分段环、倒地横姿+DOWNED；拾取菱形，危险扇形/圆边。

调色板为受控基色，不要求每资产用尽全部颜色。每种材质2–3明度层，全角色约8–12主色；单像素噪点、抗锯齿、平滑渐变不用在角色上。主文字Ivory/Panel、次文字Mist/Panel、焦点Ally/Panel需计算并实机复核4.5:1文字、3:1边界；警示对比还须检查实际腐化底图，不能以色表计算替代。

## 比例、像素与轮廓

- 640×360、固定1×镜头；1源像素=1世界/逻辑像素，整数2×/3×显示。英雄32×48画布，身体约24×32，头高约10–11px（约1/3），眼/脸留成块，剑比手大且靠外侧。
- Aren：短披肩、金色剑柄、亮色额前发束；身体不要填满画布。Thrall：32×48画布，24–32px高的瘦长破衣/偏头轮廓。Brinejaw：32×32画布，24–32px宽的低矮钳肢/壳空洞。两敌灰阶剪影也要不同。
- 预留boss64×64，其他角色不在本批制作。英雄碰撞直径仍16px；画布、剑、阴影不能扩大碰撞/攻击距离。
- 世界光源统一从画面左上；角色镜像明暗P03待G1（近对称明暗+独立脚影为候选，非已批准例外）；1px外描边、内侧少描边，底部暗/右下投影；表面2–3级阶梯色。脚底接地点固定，动画重心移动在画布内；武器的语义徽记镜像后须校正。
- 晋升复用同一骨架式像素定位与帧节奏，靠剪影新增识别：Swordmaster双刃、Abyss Swordsman幽灵披风、Sharpshooter长弓、Star Hunter星尖弓、Elemental Sage分叉元素披肩、Void Caster环杖。不是本批生产清单。

## Environment / Godot-native pipeline

先画16块以内32×32基础地砖：4安静地面、4裂缝/石板、4潮痕/边缘、4墙脚/废墟拼接。6道具：神殿核心、左右可镜像断柱、断拱模块、倒石、潮祭石、碎骨/海藻簇（左右断柱为同一设计）；32×32或32×64，神殿上限64×96。墙/拱只在边缘做视觉深度，不在行走平面制造看似阻路的高墙。保持海岸潮湿与祭祀语义，不改新地图。

地砖4×4 atlas为128×128，无抗锯齿/有损/mipmaps；Godot TileSet保留纹理padding防缝。960×540不是32整倍数：30列+16整行+最后28px视觉边条；不要把边界改成960×544。底边用裁剪Sprite2D或裁剪区域覆盖28px，不添加碰撞。

| 共同世界Canvas的最终Z目标 | 组成 / 约束 |
| --- | --- |
| -30 | TileMapLayer地面，静态，不逐帧改tile |
| -20 | 潮痕/单一腐化overlay family；低alpha、0/100两端可读；不盖危险 |
| -10 | 低矮道具/painted接触阴影；不产生动态shadow |

| 5 | 现有拾取/救援边界，清晰地面定位 |
| 10 | 项目已有攻击投射物/剑弧，角色不旋转，VFX可旋转 |
| 20 | Telegraph橙色边线/红色触发反馈；保留原geometry、寿命和contains |

## Lighting / shadows / shaders

首批依靠像素绘制亮面、静态暗色阴影贴片和神殿局部亮纹，呈现戏剧性2D光照。默认**0新增运行灯、0动态阴影、0全屏后处理、0装饰粒子层、0必需shader**。无光版本仍能读出角色/地面/危险。不降低全场亮度来假装气氛。

以后如需动态感，单独修订G1和性能方案：至多1个共享PointLight2D，限定神殿局部，禁shadow；可提议1个共享局部CanvasItem shader做调色/缓慢明暗，禁止屏幕采样、扭曲和几何位移。不同时默认启用多项；必须按SC-006测量，未达标保持关闭。粒子上限当前为0，不承诺新效果设置菜单。必须保留现有战斗效果数量，不能为美术预算删攻击。

## Animation / VFX hierarchy

最低帧、画布和逐状态FPS见[SPRITE_SPEC](SPRITE_SPEC.md)。死亡>受击>攻击/警示>移动>待机。攻击首帧即有方向/打击信息，不加伤害前摇；动画结束不控制技能。

剑弧保留原reach/angle及几何边线；已有友方追踪星用2–4帧旋转感，浅青中心与紫色外瓣。禁止给Aren魔法。威胁边界优先于冲击、冲击优先于装饰；特效不做全屏白闪。单次hurt闪白沿用现有8tick窗口与无敌闪烁语义。所有可选装饰在密集场景先退让，法术本体/警示/拾取不得消失。

## UI hierarchy

先HP/直接危险与救援，再XP/Run Lv/计时，后角色/Hero Lv/腐化/金币/同伴。共享1px暗边+1px语义focus，不做厚重画框。12px正文起步，标题16/20px，4/8/12间距。准确数值/代价/禁用原因优先于装饰图标。[UI_DESIGN](UI_DESIGN.md)定义全部原生组件和状态。

## R1 · Background replacement

CoastField仍创建四墙、保留960×540与set_corruption。新环境完整可用时停旧_draw地面/潮痕/装饰，仅显示新视觉子树；缺必要资源时隐藏新视觉并恢复完整程序背景。不能隐藏整个Field误伤子树，碰撞始终不变。验证无旧底盖新tile、无双重装饰、警示清晰和故障回退。
