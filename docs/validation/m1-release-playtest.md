# Release playtest evidence

The Windows release boots offline and loads its catalog. Through AbyssExpedition.console.exe, an external development-only graphical harness opened the packaged scenes/Resources at 1280×720, 1920×1080 and 1371×813, covering menu, selection, all three starters, combat/HUD, upgrades, pause, both boss patterns and results. Output: release-graphical.log. The harness is excluded from the package and is not required to play.

Source native suites cover terminal arbitration and retry cleanup; actual keyboard menu/movement/pause input was also exercised in a source runtime. A complete manual, unaccelerated exported-play session for every starter and every release path has not been performed, so T072 remains open. The short graphical fixture is not misreported as that manual acceptance run.
