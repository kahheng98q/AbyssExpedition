## UI 清单与设计缺口

`scenes/ui/` 大多为 Control 空壳，界面由脚本在运行时构建。因此“修改场景前批准”也覆盖运行时布局/主题脚本及关联资源；仅改脚本不能绕过 G1。

| 界面/现有源码 | 当前表现与缺口 | 拟议处理/须保留状态 |
| --- | --- | --- |
| [战斗 HUD](../../scripts/ui/combat_hud.gd) | 平顶栏长文字，腐化/队伍/救援独立标签，原型进度条 | 紧凑状态分组，区分 Hero Lv/Run Lv，HP/XP/时间、首领、双同伴/倒地、救援、腐化/金币及可发现种子/详情；切片优先 |
| [升级](../../scripts/ui/level_up.gd) | 文字按钮，效果与次数准确来自 Resource | 三张统一选择卡、清楚层级、可选共享图标；保留焦点/1–3、不可跳过/重抽、暂停与排队选择 |
| [选角](../../scripts/ui/character_selection.gd) | 已有角色文字网格/滚动、种子输入/错误，无独立头像 | 精灵裁切形象、选中/当前职业、仅可选已拥有角色、清楚种子/预览/开始；新档与全六人状态 |
| [名册](../../scripts/ui/roster.gd) | 可滚动属性/队伍/转职操作 | 紧凑共享角色行/卡；主控/同伴/倒地区别；0–2 同伴、验证、保存/取消 |
| [转职](../../scripts/ui/promotion.gd) | 两个真实程序分支预览及文字操作 | 明确双分支形象比较、当前数值/效果、保留被动、永久性/费用、锁定/选中/确认/取消 |
| [公会](../../scripts/ui/guild.gd) | 当前入口中心：章节、余额、收集路径与链接 | 克制神龛/公会框架、共享角色图标、紧凑余额；新档/收集齐/章节完成；不新增导航步骤 |
| [主菜单](../../scripts/ui/main_menu.gd) | 历史场景/脚本仍在；当前 `show_menu()` 跳转公会 | 为历史界面记录共享主视觉/标题/按钮处理；旧菜单截图不代表当前启动界面 |
| [招募](../../scripts/ui/recruitment.gd) | 池子、确认、揭晓、兑换、历史均用共享文字面板 | 同一框架/图标；十条有序结果、重复标签、概率/费用、余额不足/全拥有/空记录与中断恢复 |
| [救援提示](../../scripts/ui/rescue_prompt.gd) | 暂停文字邀请；现有区域与 HUD 显示进度 | 紧凑邀请/奖励；接受/拒绝、进行/失败/成功、Sera/重复票券、已赚取/已结算 |
