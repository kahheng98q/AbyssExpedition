# Procedural actor placeholders

Original 32×32 actor / 64×64 boss silhouettes are drawn by scripts/combat/actor_presentation.gd from VisualSet Resources. There are no external sprite-sheet dependencies. Idle/move/attack/hurt/death have explicit procedural poses, flash and priority; presentation-only snapping leaves physics continuous. See assets/provenance.md and docs/art-direction.md for replacement targets.
