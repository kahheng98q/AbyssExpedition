## 冻结素材与答卷

直接打开[离线答卷](../../../visual-design/review-session.html)。它只使用[当前冻结索引](review-material-index.json)中的180张实际引擎辨识帧、HUD和升级图。G1协议原件及批准记录不修改；[协议](../recognition-protocol.json)中的旧pending字样是冻结文件历史状态，实际批准见[审批记录](../../../visual-design/APPROVALS.md)。

1. 主持人先确定十位不同测试者，分配P01–P10匿名编号，记录真实参与和日期；不得用自动化测试、同一人多轮或AI答案充数。
2. 测试前不要展示画廊、参考答案或剪影提示。每位在本地独立打开答卷；条件/尺寸顺序随机。系统缩放100%，完整1280×720或1920×1080显示；不适合的尺寸记录缺测，不缩小成缩略图。
3. 辨识每段2秒后遮罩，再回答六项。UI先读题，显示最多5秒；找到后按空格，随后填写答案。空格只记录作答信号；正确性由主持人逐条判断。超时、切页、窗口改变或不完整曝光不得当有效通过。
4. 每人导出JSON原始答卷和CSV。页面不自动上传、不揭示答案、不计算通过；关闭前必须导出。当前自动化浏览器取消了JSON/CSV下载（原因未确定）；页面始终保留可复制原始文本，可全选复制另存，回退已测试。主持人保留原JSON，不覆盖；在CSV副本的`correct`栏独立填写`true`或`false`，未评分留空。
5. 以命名评审者的JSON记录本次素材hash、reviewer、date、预先确定的participants编号列表。合并CSV保留表头；用下列命令生成新评分文件。每个辨识项目×条件×尺寸以及每个UI任务×尺寸均需十份有效评分，至少8份正确；不能靠总平均数掩盖失败。

```powershell
python tools/score_visual_reviews.py --input-csv '<实际合并评分.csv>' --reviewer-json '<实际评审记录.json>' --output '<全新评分结果.json>'
```

现有[574组像素对照](pixel-comparison.json)、源码/发布原生图和引擎最终窗口变换均保留。原生图的放大、网页中的2×/3×播放、引擎变换记录都不能补充为操作系统窗口截图。

T033/T073/T074/T077/T080仍需实际窗口/显示观察：source和release分别检查1280×720、1920×1080、1371×779；保留完整客户区/黑边，不裁掉边缘。原始before源码/EXE见[基线](../before/manifest.json)，当前构建见[candidate](candidate-files.json)。比较时绑定同一快照、seed101、输入、tick、camera、party、敌人和腐化条件；不得把自然游玩中的不同随机状态冒充成对样本。

逐项检查正常/密集、0/100腐化、两同伴含倒地、boss警示与救援组合、四边四角、基础/升级效果回退、三卡焦点及长文。动作看四向、脚锚/镜像、atlas边缘、camera移动、暂停/恢复、迟到/受击中断/死亡清理。检查闪烁/模糊必须观看实际显示，静态PNG不能给通过结论。

自然UI会话另行走鼠标、方向键+Enter、1/2/3、按住/重复/释放后新输入、连续升级与暂停叠加、滚动、disabled原因；现有自动化注入通过不替代人的这段操作。六角色/十抽/保存错误检查保持原语义，不改真实永久存档；不要为测试花费正式票券。

## 参考机、显示延迟和正式决定

参考条件仍为Windows11、i5-8400、GTX1050Ti4GB、16GB RAM、SSD、1920×1080/60Hz、Compatibility release。原M4和P02分开，各seed101/202/303，30主动秒预热+120主动秒采样；p95≤16.67ms且p99≤25ms，逐seed判定。当前5800H/GTX1650主机只能提供补充证据。不要降低敌人/特效/弹体/宝石数或放宽门槛。
