# M4 events and coastal chapter — 2026-10-15

There are exactly three event definitions and three active-time slots: 2:00, 4:00 and 6:00. With Sera unowned, 4:00 is guaranteed rescue; other slots choose merchant/altar equally. With Sera owned, each slot samples all three kinds equally. This intentionally replaces M3's always-owned minute-four rescue. The independent SHA-256-derived event_offers stream does not consume wave/upgrade/draw RNG. Offers are frozen, identified, traced and consumed once; no boss-phase event backlog is created.

Merchant: 20 temporary coins heals the active hero by 25% max HP; 30 coins grants one party Might (+10% starting damage); Leave costs nothing. Altar: Blood Tithe costs 20% active max HP plus 25 corruption for +30% starting damage, leaving at least one HP; Unbound Assault costs 35 corruption for +40% starting attack frequency. Effects apply to living party members and persist through subsequent run upgrades. Decline is free. UI derives displayed effects and disabled reasons from validated Resources. It guards new confirmation input, including held Enter, and maps Escape to the free choice.

The existing radius-96, 1800-active-tick rescue is reused. Each owned opportunity has independent state and can earn a ticket. All completed owned rescues join the one terminal settlement; no duplicate Sera/token grant. Abandonment grants nothing. Level choices precede events, event resolution releases only its own token, and terminal state cancels stale commands. Replay stores Sera ownership, ordered offers and decisions.

Schema v3 adds only chapters.coast. Pure v2-to-v3 migration defaults false, preserves all prior progression/collection/RNG/history and retains source generations. v1 is upgraded through the existing v2 transform. Migration failure blocks play and Retry publishes identical candidate bytes. Runtime corruption/coins/health/events are forbidden in the profile. Boss victory joins chapter completion to the existing atomic settlement; UI displays saved completion only after commit. A repeat expedition resets temporary state and must defeat its own boss.

Aetheran Coast narrative, tidal shelves, cult stones, corrupted crests and the original single-eyed, tentacled Hierophant use simple procedural placeholders. No extra map, boss, hero, class, network or dependency was added.

Executed: event scheduling stub first produced 62 behavioral failures; after implementation all M4 assertions pass. Actual router and native save/reopen tests, all three source graphical sizes and exported M4 graphical harness pass. Exact costs, both buffs, insufficient coins/HP/headroom, leave/decline, held confirmation, rescue, boss warnings, chapter settlement, repeat reset and reopen were exercised. Ordinary human play and the full manual event/collision matrix remain unverified; T168 stays open.
