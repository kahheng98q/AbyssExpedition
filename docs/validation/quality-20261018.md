# Q1 战斗品质迭代 — 2026-10-18

**已实现并验证**：战斗反馈、角色/首领表现、海岸遗迹和HUD分区；**待人工验收**：是否更好玩、是否提升重试意愿、长局视觉疲劳。Godot仍为4.5纯2D，无新增付费/在线依赖，无存档格式或平衡数值变更。

## 问题与设计判断

实机基线里，人物像几何标记，海岸缺乏地点特征，敌方预警比主体醒目。已有近战是两条静止弧线；攻击姿态只增加短线，没有独立命中/击杀反馈。HUD把HP、XP、两种等级、计时和seed放在同一文本行。这些是本轮观察，不是玩家访谈结论。

本轮优先让“打中了谁、击杀没有、自己在哪里、下一件事何时发生”更可辨认，而没有增加内容量或调整强度：

| 改前 | 改后 | 验证边界 |
| --- | --- | --- |
| 静止双弧、短线姿态 | 快速扫斩、收势，箭迹/法术尾迹分开 | 实际范围与伤害tick不变 |
| 受击闪白，无命中数字 | 实际扣血数字、受伤色、击杀碎光 | 只响应接受的hit；无敌拒绝不显示 |
| 方块人物、钻石小怪、粉色首领 | 装甲/披风/武器朝向，邪教徒/灯笼/甲壳/独眼触须 | 仍为原创程序像素美术，有原创烘焙敌人图集，手工角色动画仍未完成 |
| 网格地面、少量石块 | 破碎石路、沉没圣所、潮汐浅滩与残柱 | 装饰可走，碰撞和场地尺寸不变 |
| 单行数字横幅 | 生命、局内成长、时间分区，下一事件倒计时，腐化独立卡片 | HP/XP/永久等级/seed/金币/腐化信息保留 |

设计参考：[Thomas Vasseur的动画复盘](https://www.gamedeveloper.com/production/art-design-deep-dive-using-a-3d-pipeline-for-2d-animation-in-i-dead-cells-i-)关于关键姿态与效果协同，以及[同作者场景复盘](https://www.gamedeveloper.com/production/art-design-deep-dive-giving-back-colors-to-cryptic-worlds-in-i-dead-cells-i-)。只借鉴设计原则，没有复制资产、采用其3D管线或购买素材。

### 性能复查驱动的第二次修正

首版Q1完整采样发现p95=39.482ms，明显慢于当日旧M4的15.224ms，故没有将功能通过视为交付终点。[隐藏绘制探针](quality-20261018/draw-probe-before.log)测得full=2503 calls/no_field=1162 calls，静态地形单独占1341次绘制。

将同一原创海岸用Godot离线烘焙为两张960×540 PNG（约14KB/张），运行时按腐化比例混合。原始draw_field、[烘焙工具](../../tools/bake_coast_art.gd)和碰撞墙仍保留；没有降低敌人/效果/弹体/宝石工作量。修正后[同一探针](quality-20261018/draw-probe-cached.log)full=1164/no_field=1162，即地形只需2次绘制。探针短窗口的process_ms受统计刷新周期影响，不作帧时验收。

[仅地形缓存阶段逐像素核对](quality-20261018/cache-pixel-final.log)：7帧中180–640/230400像素变化，最大RGB通道差1/255，来自RGBA8中间缓存和透明混合量化。最初严格相等比较[确实失败](quality-20261018/cache-pixel-compare.log)；后续明确采用≤1通道量化容差，0容差失败，不宣称像素完全相同。已重新查看最终画面。

缓存后重跑[content/scene_smoke](quality-20261018/cached-native/scene_smoke.log)、反馈/debug原生、全部源码与新EXE图形回归。14组5,249是本轮完整功能验证的各组结果，缓存后针对性复测不累加制造通过数。首版EXE另存于builds/windows/quality-20261018-uncached/；旧hash `F21F48DFC59BEDF9CB4C67DBEEE43B023B935347654DE5B32CCAEDD99BE58246`，历史原始日志保留在uncached-evidence/。当前hash以build-sha256.json为准。

[六人实际外观](../../screenshots/quality-20261018/actual-roster.png)由真实ActorPresentation节点渲染，用于文档展示，不是新增游戏页面；角色仍共用三种基础职业外观。展示夹具首次误读不存在的ProfessionDefinition.display_name，[报错保留](quality-20261018/gallery-engine.log)，改为已有id后[生成通过](quality-20261018/gallery-final.log)。


地形缓存后p95仍为27.867ms，于是继续把7类敌人的程序轮廓烘焙为8状态图集（正常/腐化、普通/受击、两帧动作）。英雄保持程序姿态；敌人预警圈和血条继续动态绘制。图集与生成脚本均为项目原创，没有缩减敌人数。静止诊断场景的总调用进一步从1164降到[723](quality-20261018/draw-probe-atlas.log)。图集透明边缘经过RGBA8量化，移动阴影跟随1px步态；图集阶段不主张逐像素相等，已检查最终实机截图。

图集后再次通过[content/scene_smoke](quality-20261018/atlas-native/scene_smoke.log)、反馈/debug原生，以及全部源码/新EXE三尺寸图形。中间仅地形缓存的EXE保留在builds/windows/quality-20261018-field-cache/，hash `386E1CDCB312335E56EE5DC42F2754E98B52B931673A03107BF5213E5DE769D4`；最终图集版hash `28CC8DBEC8D7F4C58AF9BDD32470CBAA9F163261CCD614A154096CE74F3C2E36`。最终图像仍在after-*；中间版本在after-field-cache-*和after-uncached-*。
