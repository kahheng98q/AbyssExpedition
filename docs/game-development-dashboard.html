02一次远征，五步循环

战斗内成长每局重置，结算后的角色成长保留。

  1. 01公会整备

    选角色与最多两名同伴

  2. 02进入海岸

    确认种子，开始移动

  3. 03作战与抉择

    拾取经验、升级、处理事件

  4. 04首领或败退

    9:00 首领登场；击败才胜利

  5. 05结算与再出发

    保存奖励、招募、成长与转职

主动放弃不发奖励。失败仍可结算已赚取奖励；已救下的 Sera 也在胜负结算时加入。

详细 Quickstart ↗

游玩与操作

  1. 双击 builds/windows/m4/AbyssExpedition.exe，或用下方固定 Godot 命令打开源码。
  2. 公会选 Expedition；换角色，输入种子（例如 101），开始远征。空种子首次生成后需再按开始。
  3. 持续走位、拾经验并选择升级。9:00 躲避首领预警，击败它获胜。
  4. 结算后进入 Roster / party / promote 调整队伍与成长，或进入招募界面。

快速测试角色与转职

  1. 用固定 Godot 4.5 打开 project.godot，按 F5。在公会的角色选择里分别测试三名初始角色。
  2. 进入战斗按 F9。Character 选择目标，增加永久等级到 15；Progression 发放转职道具，再打开转职预览。
  3. 测试另一分支可用临时分支预览。招募角色须先正常获得；沙盒仅操作已拥有角色。
  4. System → Discard session / normal menu 结束沙盒。正常游玩则靠结算经验升至 15、胜利取得道具后转职。
