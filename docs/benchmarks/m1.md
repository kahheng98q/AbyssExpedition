# Performance evidence

T068 supplies a stress fixture targeting 100 non-bosses + boss, 30 effects, at least 100 projectiles and 500 persistent gem nodes. It counts active nodes, replenishes expired effects/shots and merges excess fixture drops by exact summed XP into retained gems. This merging is benchmark-only; shipping rewards never expire. AI/hero shots can temporarily exceed the 100-projectile floor. Raw CSV records actual counts. A short headless smoke used seed 101, 1-second warmup / 2-second capture, 286 samples: p50 6.407 ms, p95 13.849 ms, p99 22.476 ms, max 23.752 ms. See smoke.log and m1-101.csv. This validates fixture execution only, not displayed FPS, a full sustained workload or reference-hardware budgets.

Graphical renderer: Compatibility / NVIDIA GeForce GTX 1650 / OpenGL 3.3 / driver 546.30. This differs from the specified GTX 1050 Ti reference. CPU/RAM/power/OS benchmark conditions were not fully measured.

T069 remains open: no three-seed 30-second warmup + 120-second capture on the reference hardware, no VSync/uncapped paired acceptance measurement and no displayed input/hit latency correlation. No speculative pooling or performance claims were added.
